# 참고: 설비 이력·인수인계 메모 현장 용어

최종 프로젝트의 `docs/` 문서(설비 이력, 교대 인수인계 메모)에 나오는 약어와 용어입니다. 문서를 읽을 때 참고합니다.

## 설비·위치 표기

| 표기 | 뜻 |
|---|---|
| 01호기, 02호기, 03호기 | ETCH_01, ETCH_02, ETCH_03 설비 |
| 03B, 01C, 02A | 설비 번호 + 챔버. 예: 03B = ETCH_03의 CH_B |
| CH | 챔버 |

## 공정·알람

| 표기 | 뜻 |
|---|---|
| P | 압력(Pressure) |
| UCL | 관리 상한선(Upper Control Limit). 넘으면 경고만 뜨고 설비는 계속 동작함 |
| warn | 경고(Warning) 알람 |
| I/L | 인터락(Interlock). 넘으면 설비가 자동으로 멈춤 |
| spec 내, in-spec | 규격 범위 안 |
| TV | Throttle Valve. 챔버 압력을 조절하는 밸브 |
| TV auto learn | TV 위치를 자동으로 다시 맞추는(재교정) 작업 |
| TV POSITION DEVIATION | TV 위치가 기준에서 벗어났다는 알람 |
| CM gauge | 챔버 압력을 재는 센서 (Capacitance Manometer) |
| leak rate check, He leak check | 챔버에 공기가 새는지, 헬륨(He) 라인이 새는지 점검 |
| ESC | 웨이퍼를 고정하는 정전척(Electrostatic Chuck) |
| MFC | 가스 유량 조절기(Mass Flow Controller) |
| RF Gen, reflected power, 매처 | 플라즈마를 만드는 전원 장치, 되돌아오는 전력, 전원을 맞춰 주는 장치 |
| 파티클 | 챔버 안의 미세 이물 |

## 작업·부품

| 표기 | 뜻 |
|---|---|
| PM | 정기 유지보수(Preventive Maintenance) |
| Wet Clean | 챔버를 열고 내부를 세정하는 작업 |
| Seasoning | PM 후 웨이퍼를 몇 장 돌려서 챔버 상태를 안정시키는 작업 |
| F/R, Edge ring, Liner, O-ring, Upper electrode, View port | 챔버 안의 소모품·부품 (포커스 링, 가장자리 링, 내벽 보호재, 밀봉 고무, 상부 전극, 관찰창) |
| 로봇 티칭, Handoff, end effector | 웨이퍼를 옮기는 로봇의 위치 설정, 웨이퍼를 주고받는 동작, 로봇 손 끝 부분 |
| Release | 점검을 마친 설비를 다시 생산에 투입 |
| Rev.14 → Rev.15 | 레시피 버전 변경 |
| CD | 식각 후 패턴 폭(Critical Dimension). 레시피를 바꾼 뒤 확인하는 값 |
| IPA 와이핑 | 알코올(IPA)로 닦아내기 |

## 메모 말투·기타

| 표기 | 뜻 |
|---|---|
| 특이X | 특이사항 없음 |
| 인계 | 다음 교대에 넘기는 일 |
| ~프로 | 사내 호칭 |
| 세진테크 | 설비 유지보수 협력사 (가상) |
| 벤더 | 설비 제조사 |

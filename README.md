# LangChain 에이전트 실습

## 설치

1. 이 페이지 우측 상단의 **Code → Download ZIP**을 클릭해 내려받습니다.
2. 내려받은 ZIP 파일의 압축을 풉니다.
3. 압축을 푼 폴더에서 `설치하기.bat`을 더블클릭하면 필요한 프로그램과 라이브러리가 설치됩니다.
4. `.env.sample` 파일을 복사해 이름을 `.env`로 바꾸고, 안내받은 API 키와 URL 값을 입력합니다.

## 진행 방식

- **설명**: 각 폴더(`1. LLM` ~ `5. FinalProject`)의 주피터 노트북을 보며 진행합니다.
- **심화**
  - `2. LangChain/02_Langchain_파이프라인_심화.ipynb` : 프롬프트 템플릿, `|` 체인, 구조화된 출력, 병렬 실행, 라우팅, 재시도·대체 모델, 체인을 도구로 쓰기
  - `6. MultiAgent/06_멀티에이전트.ipynb` : 최종 프로젝트 데이터로 슈퍼바이저, 라우터, LangGraph 워크플로(작성 → 검토 → 재작성) 구현
- **실습**: `실습안내모음` 폴더의 안내 문서를 보며 직접 구현합니다.
